# StutterClear (backup demo)

StutterClear removes stutters from a person's own voice: live in calls, and on recordings. This
Space is the always-on backup demo; it runs on a free CPU, so live cleaning uses the rule-based
detector and voice notes are off. The full version (the WavLM teacher live on a GPU, voice notes,
dictation, Clean my video) runs from the team's laptop link.

Code and measured results: https://github.com/Pradyuman-aviator/stutterClear

Demo clips: read speech from LibriSpeech (Panayotov et al., 2015; CC BY 4.0) with synthetic
stutters inserted by StutterClear. Nothing a visitor says is stored.
